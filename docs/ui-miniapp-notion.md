# reairss 小程序 UI 规格（Notion 风，含浅色/暗色）

> 目标：对齐 `docs/prd1.0.md` 的 V1 MVP（阅读｜找源｜订阅｜我的），用“极简 + Notion 风”定义可直接实现的 UI 决策；避免依赖复杂动效与重阴影，靠排版与留白建立层级。

## 1. 全局原则

- 低噪音：少图标、少按钮、少彩色；把交互放到“整行可点”和“主 CTA 只留一个”上。
- 低层级：弱阴影，优先用分割线与背景层级色。
- 文本优先：标题/元信息/摘要三层；最多两档字重（Regular/Medium/Semibold）。
- 触控友好：任何可点元素高度 ≥ 44px；列表项推荐 76–88px。

## 2. 主题与 Token（语义色）

> 建议所有页面/组件只引用语义 Token，不直接写色值。

### 2.1 Light

- `--bg`: `#F7F7F5`
- `--surface`: `#FFFFFF`
- `--text`: `#191919`
- `--text2`: `#6B6B6B`
- `--divider`: `#ECECEA`
- `--border`: `#E6E6E3`
- `--primary`: `#2F80ED`
- `--danger`: `#E5484D`

### 2.2 Dark

- `--bg`: `#0F0F0F`
- `--surface`: `#171717`
- `--text`: `#EDEDED`
- `--text2`: `#A3A3A3`
- `--divider`: `#242424`
- `--border`: `#2A2A2A`
- `--primary`: `#60A5FA`
- `--danger`: `#FB7185`

## 3. 排版与栅格（实现级数值）

- 页边距：左右 16px；列表容器上/下 8–12px
- 间距体系：8pt（8/12/16/20/24）
- 圆角：卡片/面板 16；按钮 12；Chip 999
- 分割线：1px，颜色用 `--divider`

### 3.1 字号/行高

- 页面标题：18 / 24，Semibold
- 列表标题：16 / 22，Medium（最多 2 行）
- 正文/摘要：14 / 20，Regular（最多 2 行）
- 辅助信息：12 / 16，Regular（来源、时间、提示）

## 4. 组件规范（建议组件化复用）

### 4.1 TopBar（自定义或系统）

- 左：标题（阅读/找源/订阅/我的）
- 右：最多 1 个轻量动作（筛选/搜索/设置），避免“工具条感”

### 4.2 Chip（筛选/分类）

- 高度：28–32px；左右内边距 10–12px
- 默认：描边 `--border` + 文字 `--text2`
- 选中：底色用 `--primary` 的 8–12% 透明度 + 文字 `--primary`

### 4.3 列表项：FeedItem

- 结构：标题(2行) / 元信息（来源·时间）/ 摘要(2行，可选)
- 点击：整行可点；按压态用 `--surface` 到 `--bg` 的轻微变化（不做强波纹）

### 4.4 列表项：SourceItem

- 结构：源名 / 简介(1–2行) / 分类标签（可选）
- 右侧按钮：
  - 未订阅：主按钮（文字“订阅”）
  - 已订阅：描边按钮（文字“已订阅”）

### 4.5 Empty / Loading

- 空态：标题 + 一句说明 + 单个 CTA（去找源/去订阅）
- Loading：骨架优先（浅色用 `--divider`，暗色用 `--border`）

## 5. 页面级布局（对齐 PRD）

### 5.1 阅读（Feed）

- 顶部：时间范围 Chip（`24h / 3d / 7d`）
- 列表：FeedItem；支持下拉刷新 + 游标分页
- 空态区分：
  - 无订阅：引导去「找源」
  - 有订阅但无内容：提示“暂无更新”

### 5.2 找源（源库 + 搜索）

- 搜索框：吸顶；圆角 12；占位“搜索 RSS 源”
- 分类：横向 Chip（可滚动）
- 列表：SourceItem（右侧订阅按钮）

### 5.3 订阅（我的订阅）

- 列表：订阅源列表；点击进入 Feed 并按源筛选
- 取消订阅：建议二次确认弹窗（避免误触）

### 5.4 我的（设置）

- 主题：跟随系统 / 浅色 / 暗色（单选）
- 协议：用户协议 / 隐私协议入口（审查必备）

### 5.5 详情（Content）

- 标题（允许 2–3 行）
- 元信息：来源 + 发布时间（必显示来源）
- 摘要：`raw_summary`
- 主 CTA：底部固定按钮“查看全文” → 中转页

### 5.6 中转确认（Redirect）

- 强提示：来源域名 + 风险提示文案
- 按钮：主按钮“继续访问”，次按钮“返回”
- 约束：禁止自动跳转，必须手动确认

## 6. Figma 对齐建议（便于后续 MCP 抽取）

- 用 375×812 Frame（已在文件中创建）：阅读-浅色/暗色、找源-浅色/暗色、详情-浅色/暗色
- 统一用 Auto Layout 搭列表项（FeedItem / SourceItem），把间距/行高固定为上面的数值
- 将 Token 建成 Variables（Color Styles/Variables），确保浅色/暗色切换是“变量切主题”，而不是复制粘贴改色

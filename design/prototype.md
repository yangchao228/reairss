# Prototype Specification - Notion 极简风格

> 本文档定义所有页面的结构、组件、交互行为和状态管理。严格遵循 Notion 极简风格原则。

## 1. 全局原则

### 1.1 设计原则
- **低噪音**：少图标、少按钮、少彩色
- **低层级**：弱阴影，优先用分割线与背景层级色
- **文本优先**：标题/元信息/摘要三层结构
- **整行可点**：提升触控体验
- **主 CTA 单一**：避免选择困难

### 1.2 通用布局规范
- 页面背景：`--bg`
- 内容区域：`--surface`
- 列表项间距：1px 分割线（`--divider`）
- 页边距：左右 16px
- 安全区域：底部 60px（为 TabBar 预留）

## 2. 组件库

### 2.1 TopBar（顶部导航栏）

**结构**
```
┌─────────────────────────────┐
│  [标题]            [动作]   │
└─────────────────────────────┘
```

**规格**
- 高度：44px
- 背景：`--surface`
- 底部边框：1px `--divider`
- 内边距：12px 16px

**状态**
- 默认：显示页面标题
- 带动作：右侧最多1个图标按钮

**实现**
```jsx
<TopBar>
  <Title>阅读</Title>
  <Action icon="filter" /> // 可选
</TopBar>
```

## 3. 页面规范

### 3.1 阅读页（Feed）

**页面结构**
```
┌───────────────────────────────┐
│ TopBar: 阅读                  │
├───────────────────────────────┤
│ [24h] [3d] [7d]              │ ← 时间筛选 Chips
├───────────────────────────────┤
│ FeedItem                      │
├───────────────────────────────┤
│ FeedItem                      │
├───────────────────────────────┤
│ FeedItem                      │
├───────────────────────────────┤
│ ...                           │
└───────────────────────────────┘
```

**组件组合**
1. TopBar（固定顶部）
2. Chip 筛选区（吸顶，背景 `--surface`）
3. FeedItem 列表（可滚动）
4. TabBar（固定底部）

**交互行为**
1. **下拉刷新**
   - 触发：下拉距离 > 50px
   - 动画：系统默认刷新指示器
   - 完成：更新列表 + 提示文字（toast）

2. **上拉加载更多**
   - 触发：滚动到底部前 100px
   - 显示：`加载中...`
   - 完成：追加新内容

3. **时间筛选**
   - 点击 Chip：切换时间范围
   - 默认选中：24h
   - 切换后：列表重新加载

4. **点击 FeedItem**
   - 跳转：内容详情页
   - 路由：`/pages/content/content?id=xxx`

**状态管理**
```javascript
{
  timeRange: '24h' | '3d' | '7d',  // 当前时间范围
  items: Array<FeedItem>,          // 内容列表
  cursor: string | null,           // 分页游标
  hasMore: boolean,                // 是否有更多
  loading: boolean,                // 加载中
  refreshing: boolean,             // 刷新中
  error: Error | null              // 错误信息
}
```

**空状态场景**
1. **无订阅**
   - 标题：`还没有订阅源`
   - 说明：`去找源页面订阅感兴趣的内容`
   - 按钮：`去找源`

2. **有订阅但无内容**
   - 标题：`暂无更新`
   - 说明：`订阅的源还没有新内容`
   - 按钮：无

### 3.2 找源页（Discover）

**页面结构**
```
┌───────────────────────────────┐
│ TopBar: 找源                  │
├───────────────────────────────┤
│ SearchBar                     │ ← 搜索框
├───────────────────────────────┤
│ [全部][科技][技术][设计]...   │ ← 分类 Chips
├───────────────────────────────┤
│ SourceItem                    │
├───────────────────────────────┤
│ SourceItem                    │
├───────────────────────────────┤
│ ...                           │
└───────────────────────────────┘
```

**组件组合**
1. TopBar（固定顶部）
2. SearchBar（吸顶）
3. 分类 Chip 列表（横向滚动，吸顶）
4. SourceItem 列表（可滚动）
5. TabBar（固定底部）

**交互行为**
1. **搜索**
   - 输入：防抖 300ms 后触发搜索
   - 匹配：名称、简介、分类
   - 清空：显示清空按钮

2. **分类筛选**
   - 点击 Chip：切换分类
   - 默认：全部
   - 单选模式

3. **订阅/取消订阅**
   - 点击按钮：调用订阅 API
   - 成功：
     - 按钮状态切换
     - Toast 提示：`已订阅` / `已取消订阅`
   - 失败：Toast 提示错误信息

4. **排序**（可选）
   - 默认：热度排序
   - 可选：字母排序

**状态管理**
```javascript
{
  keyword: string,                 // 搜索关键词
  category: string,                // 当前分类
  sort: 'hot' | 'alpha',          // 排序方式
  sources: Array<Source>,          // 源列表
  loading: boolean,
  error: Error | null
}
```

**空状态场景**
- 标题：`未找到相关源`
- 说明：`试试其他关键词`
- 按钮：无

**状态管理**

## 4. 全局交互规范

### 4.1 页面跳转
- 使用：`wx.navigateTo`（保留历史）
- 返回：`wx.navigateBack()`
- 重定向：`wx.redirectTo`（不保留历史）

### 4.2 Toast 提示
- 位置：屏幕中央
- 持续时间：1500ms
- 样式：系统默认
- 场景：
  - 订阅成功
  - 取消订阅成功
  - 刷新成功
  - 错误提示

### 4.3 下拉刷新
- 启用页面：阅读页
- 触发距离：> 50px
- 指示器：系统默认
- 完成后：Toast 提示（可选）

### 4.4 加载状态
- 首次加载：骨架屏
- 加载更多：底部 Loading 文字
- 刷新：顶部刷新指示器

### 4.5 错误处理
- 网络错误：Toast 提示 + 重试按钮
- 数据错误：空状态页面
- 未知错误：通用错误提示

### 4.6 防抖/节流
- 搜索输入：防抖 300ms
- 滚动加载：节流 200ms
- 按钮点击：防抖 500ms
